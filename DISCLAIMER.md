# Disclaimer

This repository is an independent public reference implementation for a small workshop catalogue import workflow.

The PDF fixtures, JSON input contract, outputs, and database schema are illustrative. They are not real source documents, operational records, legal records, safety guidance, procurement recommendations, or production data.

The importer creates draft records and review warnings only. A human reviewer remains responsible for checking source evidence, resolving warnings, and deciding whether any record is suitable for an actual shared catalogue system.

This repository does not include production authentication, deployment hardening, private integrations, durable backups, or environment-specific approval policy. Those concerns must be designed for the real operating environment before production use.
